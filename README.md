# 🎙️ AI Content Summarizer

A local AI-powered content summarization app built with **Python + Streamlit + Ollama**.

Paste:
- YouTube URLs
- podcast transcripts
- articles
- blogs
- meeting notes
- long-form text

…and generate structured AI summaries completely **locally** using Ollama.

---

# ✨ Features

## ✅ Current Features

- 🎥 YouTube transcript summarization
- 📝 Long-form text summarization
- 🤖 Local LLM support using Ollama
- 📌 Structured markdown summaries
- 🎯 Multiple output styles
- 🧠 Actionable takeaways extraction
- 💼 LinkedIn post generation
- ⚡ Fully local and private

---

# 🛠 Tech Stack

- Python
- Streamlit
- Ollama
- Llama 3.2
- youtube-transcript-api
